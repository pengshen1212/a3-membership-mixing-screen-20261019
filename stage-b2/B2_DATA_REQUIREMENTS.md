# Stage B2(新城市/新路网)数据需求——运行方决定不自动启动

按用户 2026-10-20 委托("你做决定"),B2 的决定如下:**B2 存在硬性外部数据依赖,本机没有第二个城市的数据,不能也不应自动生成或伪造;因此 B1 通过后不自动跑 B2,而是在本文件登记数据需求,由用户/学校端提供数据后再预注册启动。**

## 为什么 B2 是真正的外部效度步骤

perm3(Stage A)与 perm4(B1)都是 Porto 同一张路网上的实例:节点、路型群组、边界二元群组、标签完全相同,只有区域成员不同。两个实例通过只能支持"实例级复现";城市级外推(不同路网结构、不同区域划分来源、不同速度分布)必须换网络。

## 需要的数据(最低集)

| 文件 | 对应本机角色 | 要求 |
|---|---|---|
| 新城市 `roadmap.geo` | 路段几何(geo_id, coordinates, highway, oneway, tunnel, bridge, lanes, length, maxspeed) | OSM 导出格式;本机的表头桩届时必须换成真文件 |
| 新城市 `roadmap.rel` | 路段邻接(origin_id, destination_id) | 决定边界二元群组与 d_i=2+b_i;exact 恒等依赖它 |
| 新城市 `seg2region.csv` | 区域划分(geo_id, region_id) | 连续区域 id;划分来源需说明(网格/行政区划/聚类) |
| 新城市轨迹 | 生成 `w_by_hop_sparse.npz`(hop 先验)与 `win_speed.csv`(速度标签) | 需与 Porto 处理同口径(48 时窗、speed<35 过滤等);若只求机制复现不重算 hop 权重,须显式声明替代方案并预注册 |
| (可选)`edge_attr.csv` | 邻接角度/距离特征 | 若缺失需按 `get_edge_attr` 重算(需要真 geo) |

## 资格检查(数据到手后、预注册前)

1. 节点数、区域数、大小分布与 Porto 的差异报告(外推幅度);
2. 有标签道路数(对应 Porto 的 9,384)——**判据阈值 ±0.02/±0.01 m/s 是否仍适用于新城市的速度尺度须在预注册时重审并明确**;
3. `dataset.py`(MapManager.gps2grid)需要真实现或替代网格方案——当前本机是永不执行的桩;
4. 共享输入跨臂一致性、区域 id 连续性、b_i 分布等,复用 Stage A 的验证 battery。

## 预算草案(供预注册参考)

- 训练:RR/PP/PR 全臂 25 次 + 复现校验 1 次(新城市无认证复用来源),~7h,cap 10h;
- 预处理与资格检查:视数据形态,数小时 CPU;
- 判据:主指标 Δ_content,四类判定;阈值按第 2 条重审结论写入。

## 边界

- B2 未获数据前不启动;数据由用户提供,不由运行方生成。
- B1 若不通过,按停止规则独立选题终止,B2 一并取消。
